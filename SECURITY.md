# Security policy

## Reporting a vulnerability
Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/ciprik13/chira-sweets/security/advisories/new).

Include a description, steps to reproduce and the potential impact. You will receive an acknowledgement within 7 days.

## Supported versions
Only the latest release deployed at https://chirasweets.md is supported.
